# CandyCapture Photography Billing Portal

A professional billing and invoice management system.

## Live URL
https://billing.candycapturephotography.in

## Login
- Username: admin
- Password: candy2024

## Features
- Customer Management
- Invoice Creation
- PDF Generation (pink/white theme)
- WhatsApp Integration
- Authentication

## Tech Stack
- React 18 + Vite
- Tailwind CSS
- jsPDF
- Cloudflare Pages

## Cloudflare Environment Variables
- VITE_INITIAL_ADMIN_USERNAME=admin
- VITE_INITIAL_ADMIN_PASSWORD=candy2024
- VITE_APP_URL=https://billing.candycapturephotography.in
- VITE_STORAGE_TYPE=localStorage
- VITE_SESSION_TIMEOUT_MINUTES=60

## Development
npm install
npm run dev
npm run build
